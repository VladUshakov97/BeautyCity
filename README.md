# BeautyCity Bot
Телеграм-бот для автоматизации записи в салон красоты.
Учебный командный проект в рамках курса devman.org.

## 📌 Описание
Бот позволяет клиентам самостоятельно записываться на процедуры через `Telegram`, выбирая салон, услугу, мастера, дату и время.
Реализованы четыре сценария записи, промокоды, согласие на обработку персональных данных, удобный календарь и демо‑версия онлайн‑оплаты.

## 🚀 Функционал
1. Четыре сценария записи:

    * Запись через салон *(выбор салона → услуги → мастера → дата/время)*

    * Запись через мастера *(выбор мастера → услуги мастера → дата/время)*

    * Запись через услугу *(выбор услуги → мастера по услуге → дата/время)*

    * Запись по телефону *(выбор по телефону → контактный телефон)*

2. Промокоды на скидку: *kid20* (20%), *birthday* (15%), *man10* (10%)

3. Согласие на обработку персональных данных (отправка файла, кнопка «Согласен»)

4. Календарь для выбора даты (инлайн-клавиатура, ограничение 7 дней)

5. Свободные слоты – занятые не показываются, для текущего дня скрываются прошедшие

6. Демо‑оплата онлайн – после записи предлагается оплатить (заглушка)

7. Подтверждение записи с проверкой всех данных и сохранением в БД

## 🛠 Технологии
* `Python 3.10`+

* `pyTelegramBotAPI` (`Telegram Bot API`)

* `PostgreSQL`

* `psycopg2-binary`

* `python-dotenv`

## ⚙️ Установка и запуск
1. Клонируйте репозиторий
    ```bash
    git clone <https://github.com/VladUshakov97/BeautyCity.git>
    cd beaty_bot
    ```
2. Создайте и активируйте виртуальное окружение
    ```bash
    python -m venv venv
    source venv/bin/activate      # Linux/Mac
    venv\Scripts\activate         # Windows
    ```
3. Установите зависимости
    ```bash
    pip install -r requirements.txt
    ```

4. Настройте `PostgreSQL`
* Установите `PostgreSQL` и запустите службу.

* Создайте базу данных beauty_base.

* Выполните SQL-скрипты:

    `create_table.sql` – создание таблиц (включая колонки agreed, promo_code, feedbacks).

    `insert_data.sql` – заполнение тестовыми данными.

* (Опционально) `helper.sql` – скрипты для сброса согласий и очистки данных.

5. Настройте переменные окружения
Создайте файл `.env` в корне проекта и укажите:
    ```env
    TELEGRAM_TOKEN=ваш_токен_бота
    DB_HOST=localhost
    DB_PORT=5432
    DB_NAME=beauty_base
    DB_USER=postgres
    DB_PASSWORD=ваш_пароль
    ```

6. Запустите бота
```bash
python bot.py
```
## 📌 Дополнительно
Файл согласия должен называться `agreement.docx` (или `agreement.txt`) и лежать в корне проекта.

Тестовые данные уже загружены через `insert_data.sql`.

Для сброса согласия используйте `helper.sq`l (например, для повторного тестирования).

Все изменения в БД (добавление колонок) учтены в `create_table.sql`.
